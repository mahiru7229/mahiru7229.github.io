Background image guide
======================

Recommended quick customization:
- Put your preferred background image in this folder.
- Rename it to: background.jpg
- The page will automatically use ./assets/background.jpg.

Alternative:
- Edit the CONFIG.backgroundImage value in index.html.

Download links guide:
- Edit the CONFIG.downloads object in index.html.
- Replace the placeholder ./downloads/... URLs with your real paths or hosted URLs.

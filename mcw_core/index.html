Install with pip

Use this if the package is available on an index or internal package feed.

Command 
pip install mcw-core

Recommended notes

  • Use a virtual environment for cleaner dependency isolation.
  • Pin an exact version when reproducing builds.
  • Document Python version requirements on your release page.

Install from a local wheel

Use this when distributing the `.whl` file directly.

Command

When to use this

  • Offline or internal deployment.
  • Testing the exact release artifact before public publication.
  • Controlled distribution in a local environment.

FAQ

Use this area to answer the most common visitor questions.

Can I use this as a standalone single HTML page?

Yes. This file is fully self-contained except for the optional background image path. It works as a single landing page and can later grow into a multi-page docs portal.

How do I change the background image?

The simplest method is replacing ./assets/background.jpg with your own image. You can also use the built-in background picker at the bottom-right of the page for previewing another image locally.

Where do I update download links and file names?

At the bottom of the HTML there is a single JavaScript CONFIG object. Edit the package version, file names, and links there once, and the page updates the main buttons automatically.

Can this page host separate docs pages later?

Absolutely. Replace the placeholder docs buttons with paths such as docs/index.html, docs/api.html, or your hosted documentation URLs.

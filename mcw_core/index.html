Installation

Pick the workflow that matches how you consume MCW Core.

Python
python -m pip install ./mcw_core-1.8.0-py3-none-any.whl

Download the wheel from the latest release first. A virtual environment is recommended.

git clone https://github.com/mahiru7229/mcw-launcher-core.git
cd mcw-launcher-core
python -m venv .venv
python -m pip install -e '.[dev]'
python -m pytest test -q

Activate the venv before installing. On Windows PowerShell use .\.venv\Scripts\Activate.ps1.

mcw-core-launch --root ./mcw-data --list
mcw-core-rpc --stdio
mcw-core-rpc --http --port 38475

The CLI can list/launch instances or start the headless JSON-RPC 2.0 daemon without the MCW Launcher GUI.

FAQ

Quick notes about downloads, docs and background customization.

How does the docs reader stay updated?

It queries the public Core repository tree, finds Markdown files under docs/ plus key root docs, then fetches and renders the selected file from the repository's main branch.

How do I change this Core page background?

Add or replace mcw_core/assets/background.jpg in this website repository. If the file exists, it is used automatically. If it is absent or cannot load, the original gradient background is kept. There is no upload button on the website.

How do I change the main card background?

Add assets/img/bg/custom_bg.jpg. If it exists it overrides the card background; otherwise assets/img/bg/user_bg.jpg remains the default.

Where should release downloads live?

The page tries GitHub Releases first. A wheel, full-source archive, and docs bundle are matched by filename. If no matching release asset is available, source download falls back to the repository ZIP and other buttons direct users to Releases or live docs.

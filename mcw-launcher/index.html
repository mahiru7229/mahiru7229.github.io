Rõ ràng khi tải, an toàn khi sửa.

MCW Launcher ưu tiên instance độc lập, tiến trình có thể theo dõi và khả năng phục hồi khi game, mod hoặc modpack gặp lỗi.

INSTANCE-FIRST

Mỗi cấu hình có không gian riêng

Game directory, mod loader, mods, saves, RAM, Java và runtime được tách biệt. Clone, import, export, backup hoặc repair mà không chạm nhầm dữ liệu khác.

PROGRESS THỐNG NHẤT

Biết launcher đang làm gì

Tốc độ, dung lượng và số file còn lại xuất hiện khi tải Minecraft, Java, loader, mod, modpack và bản cập nhật launcher.

FABRIC + FORGE

Mod loader theo từng instance

Tạo, thay đổi và repair Fabric hoặc Forge. Phiên bản tương thích được chuẩn bị trước khi metadata instance được cập nhật.

TÀI KHOẢN AN TOÀN

Offline và Microsoft Account

OAuth PKCE, nhiều tài khoản Microsoft, SQLite và Windows DPAPI bảo vệ refresh token. Log và diagnostics tự che dữ liệu nhạy cảm.

MODPACK UPDATE & REPAIR

Khôi phục file managed an toàn

Kiểm tra file thiếu hoặc sai checksum, bỏ qua file đã đúng, backup trước thao tác và rollback nếu update hoặc repair thất bại.

GIAO DIỆN THÍCH ỨNG

Vừa màn hình, dễ đọc hơn

Tự chọn bố cục phù hợp cho 1366×768 và 1920×1080, dialog tương phản cao, RAM slider kèm ô nhập MB chính xác.

Cài đặt trong một phút

Tải ZIP, giải nén, rồi Launch.

1

Chọn Release hoặc Beta

Dùng bản phát hành cho chơi thông thường; chỉ dùng Beta khi muốn tham gia thử nghiệm.

2

Giải nén toàn bộ ZIP

Đặt launcher ở đường dẫn ngắn như C:\MCW. Không chạy EXE trực tiếp trong ZIP.

3

Mở MCW Launcher.exe

Windows SmartScreen có thể cảnh báo vì EXE chưa ký số. Chỉ tiếp tục khi tải từ GitHub chính thức.

Quick answers

Trước khi bạn tải.

MCW Launcher có miễn phí không?+

Có. Dự án được phát hành mã nguồn mở theo giấy phép MIT.

Release và Beta khác nhau thế nào?+

Release là kênh ổn định cho sử dụng thông thường. Beta/RC dành cho tester và có thể còn thay đổi hành vi hoặc phát sinh lỗi.

Website lấy phiên bản ở đâu?+

Danh sách phiên bản, asset và release notes được đồng bộ từ GitHub Releases của dự án.

Nếu GitHub API tạm thời không truy cập được thì sao?+

Trang có cache cục bộ và dữ liệu dự phòng để archive vẫn có nội dung cơ bản thay vì trống hoàn toàn.

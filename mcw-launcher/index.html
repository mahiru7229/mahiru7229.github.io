01 / WHY MCW

Minecraft modded rất vui.

Quản lý nó thì không.

MCW được xây quanh một ý tưởng đơn giản: launcher nên gánh phần lộn xộn để bạn tập trung vào việc chơi.

02 / THE SYSTEM

Một flow.
Không phải
mười công cụ.

Từ world mới đến một modpack nặng, mọi thứ đi qua cùng một hệ thống.

01
CREATE

Worlds, not folders.

Mỗi instance có game directory, save, RAM, loader, Java và mods của riêng nó. Bạn có thể clone, import hoặc thử nghiệm mà không chạm nhầm world khác.

RESOLVE

Java becomes invisible.
